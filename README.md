# Каталог коллекции марок

Статический сайт для GitHub Pages, без зависимостей. Откройте `index.html` или запустите `python -m http.server 8000` в этой папке.

Текущий каталог: 10 исходных файлов, 9 разных страниц, 61 физическая марка. `photo_2026-11-02_10-32-34.jpg` побайтно совпадает с `photo_2026-11-02_10-20-09.jpg`: сохранён и отмечен как повтор, не увеличивает оценку. Распознавание сохранено; все 61 цены пересчитаны исключительно по RusPhil 02.11.2026. Условный каталожный итог — 1509–1870 ₽. Рыночная оценка и оценка продажи альбомом удалены.

## Добавление страниц и альбомов

1. Положите исходную фотографию в `media/`.
2. Добавьте страницу в `pages` нужного альбома в `data.js`.
3. Для нового альбома добавьте объект в `albums` с уникальным `id`.

Формат строки: `[положение, название, номинал, номер Соловьёва, состояние, минимум, максимум, уверенность, цены]`. Поле `цены` содержит `basis` (`mint`, `used`, `uncertain`) и список ключей `variants`. Исходные пары `[MNH, CTO/U]` в рублях сохранены в `catalogue.entries` внутри `data.js` со ссылкой и датой проверки. Строки 5 и 6 содержат минимум/максимум выбранных вариантов, без скидок и надбавок. При `mint` используются MNH, при `used` — CTO/U, при `uncertain` — оба столбца. Для марок без явного гашения MNH применяется условно до проверки оборота. Неподтверждённые разновидности перечислены отдельно. Для Шевченко с купоном применяется цена строки № 2549 без дополнительной наценки.

Значение `check` показывает пометку об уточнении. Повторы марок считаются отдельными физическими экземплярами; повторные фотографии перечисляются в `duplicatePhotos`, в `pages` не добавляются. Разные марки считаются по полю номера Соловьёва, без разделения разновидностей. Все текущие базовые выпуски — 1961 года; для стандартов не исключены поздние переиздания. Для других лет добавьте соответствующий источник в функцию `source`. Дата обновления самих цен RusPhil не установлена.

Ссылка с номера ведёт на каталог RusPhil 1961 года с текстовым якорем номера. Поддержка перехода к текстовому фрагменту зависит от браузера. Номинал Лумумбы сохранён по фотографии (2 коп.), несмотря на 4 коп. в источнике. Для № 2634 источник указывает 2 коп., прежняя пометка о расхождении удалена. Исходные фотографии сохранены без изменения.

Для публикации: репозиторий `stamp-collection`, GitHub Pages → Deploy from a branch → `main` → `/ (root)`.

Автоматическая публикация из PowerShell: после `gh auth login -h github.com --web` запустите `powershell -ExecutionPolicy Bypass -File .\publish.ps1`. Скрипт проверяет аккаунт, создаёт публичный репозиторий при отсутствии, отправляет исходники и включает GitHub Pages. Существующий origin другого проекта не меняется, принудительная отправка не используется.
