# Каталог коллекции марок

Статический сайт для GitHub Pages, без зависимостей. Откройте `index.html` или запустите `python -m http.server 8000` в этой папке.

## Альбомы

- **Альбом 1961:** 9 страниц, 61 физическая марка, условный итог **1509–1870 ₽** по RusPhil. Первоначальные данные и цены сохранены. Повторный файл фото хранится в архиве, но не увеличивает количество страниц, марок или сумму.
- **Иностранные марки:** 3 исходные фотографии, 50 физических экземпляров. По 30 маркам найдены цены; частичный справочный итог **176,84–256,93 USD**. Из них 29 марок оценены по Scott 2013 (176,25–254 USD), одна — по StampWorld (0,59–2,93 USD). Цена остальных 20 не включена: скрытые номиналы, неустановленные разновидности, оригинал/переиздание или не найденная подтверждённая цена.
- **Кляссер б/у:** 16 страниц (8 листов), 210 × 160 мм. Предварительный ориентир **100–300 ₽** за один кляссер без марок; это приблизительная оценка по близкому аналогу, а не каталожная стоимость или подтверждённая цена сделки. В сумму марок не прибавляется.

Китайские цены — USD из Scott Standard Postage Stamp Catalogue 2013, печатные страницы 351–360, страницы PDF 2–11. Ссылки ведут на внешнюю копию PDF; сам PDF не распространяется в репозитории. Для японского тоннеля Хокурику использован StampWorld, № 786 / Scott № 761, MNH 2,93 USD и Used 0,59 USD. Номера этих каталогов не взаимозаменяемы. Проверка источников: 02.11.2026. Цены Scott 2013 не выдаются за текущую рыночную оценку. Частичный итог объединяет справочные значения разных изданий в одной валюте; рубли и USD не суммируются.

## Данные и расширение

Строка марки: `[положение, название, номинал, номер каталога, состояние, минимум, максимум, уверенность, цены]`.

Для СССР поле `цены` содержит `basis` (`mint`, `used`, `uncertain`) и ключи `variants`. Исходные пары `[MNH, CTO/U]` в рублях сохранены в `collection.catalogue.entries`. Ссылка с номера ведёт на соответствующий текстовый фрагмент RusPhil за 1961 год. MNH без явного гашения используется условно до проверки клея; все существовавшие оговорки сохранены.

Для иностранного альбома собственный `catalogue` задаёт валюту и подписи. Поле `цены` у строки содержит `url`, `mint`, `used`, `basis`, при необходимости `sourceName`, `identityUrl`, `reason` и `referenceOnly`. Scott 2013 — источник по умолчанию для ссылок на ibchen; StampWorld подписан отдельно. Исходная колонка Unused не означает MNH для всех китайских выпусков: S38 оценена каталогом без клея, как выпущена.

`null` в полях минимума и максимума означает **не оценено**, не ноль. `referenceOnly` позволяет показать цену конкретного оригинала/варианта справочно, не присваивая её неустановленному экземпляру. Для ранних китайских выпусков необходимо отличать переиздания 1955 года. Число оценённых марок показано у каждого итога. Дубликаты марок считаются отдельными экземплярами; полные серии дополнительно не суммируются.

Исходные фотографии сохранены побайтно: иностранные — в `media/foreign/`, СССР — в `media/`. Чтобы добавить альбом, добавьте объект в `albums`, страницы в `pages`, исходники в `media/`. Все данные и CSV используют оригинальную валюту источника. Методики и альтернативные источники в `index.html` переключаются вместе с альбомом.

`collection.accessories` хранит отдельные оценки принадлежностей со своими источниками, валютой и пояснениями.

## Публикация

Репозиторий: `PavelDykhne/stamp-collection`. GitHub Pages: ветка `main`, корень.

Из PowerShell запустите `powershell -ExecutionPolicy Bypass -File .\publish.ps1` с уже настроенным GitHub CLI. Скрипт проверяет аккаунт и origin, сохраняет и отправляет сайт, включает Pages при необходимости. Принудительная отправка не используется. Конфигурация авторизации находится вне репозитория и в архив сайта не включается.
