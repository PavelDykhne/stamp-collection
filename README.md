# Каталог коллекции марок

Статический сайт для GitHub Pages, без зависимостей. Откройте `index.html` или запустите `python -m http.server 8000` в этой папке.

## Добавление страниц и альбомов

1. Положите исходную фотографию в `media/`.
2. Добавьте страницу в `pages` нужного альбома в `data.js`.
3. Для нового альбома добавьте объект в `albums` с уникальным `id`.

Формат строки: `[положение, название, номинал, номер Соловьёва, состояние, минимум, максимум, уверенность]`. Значение `check` показывает пометку об уточнении. Итоги рассчитываются автоматически; цена лота задаётся отдельно через `lot`. Указывайте `lot: null`, если она ещё не оценена. Повторы считаются отдельными физическими марками. Разные марки считаются по номеру Соловьёва, без разделения разновидностей. Все страницы текущей версии — 1961 года; для других лет добавьте соответствующий источник в функцию `source`.

Ссылка с номера ведёт на каталог RusPhil 1961 года с текстовым якорем номера. Поддержка перехода к текстовому фрагменту зависит от браузера. Данные распознавания и цены предварительные, перенесены из переписки 02.11.2026; подтверждённых завершённых сделок нет. Номинал Лумумбы сохранён по фотографии (2 коп.), несмотря на ошибку 4 коп. в источнике.

Для публикации: репозиторий `stamp-collection`, GitHub Pages → Deploy from a branch → `main` → `/ (root)`.

Автоматическая публикация из PowerShell: после `gh auth login -h github.com --web` запустите `powershell -ExecutionPolicy Bypass -File .\publish.ps1`. Скрипт проверяет аккаунт, создаёт публичный репозиторий при отсутствии, отправляет исходники и включает GitHub Pages. Существующий origin другого проекта не меняется, принудительная отправка не используется.
